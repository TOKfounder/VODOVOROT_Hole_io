# Stage 3 — original music auditions

These four short instrumental compositions are the **first approval milestone**.
They are not full release tracks. No scene starts them automatically, and no
90–120 second release arrangements have been created.

Current audition set: **revision 2, not approved**. The author requested a different sound and a specific listening reference is pending. This set is retained only for comparison. It was made following the author’s request for more playful game-like melodies and fewer whistling timbres. The first wind-led demos were not approved.

- `menu`: **Pocket Whirl**, 27.88 s, 110 BPM. Physical plucked-string hook, warm keys, rounded bass and dry wooden/paper percussion.
- `city`: **Sidewalk Bounce**, 28.37 s, 108 BPM. Dry piano/EP, clipped string answers, syncopated bass and a light funky groove.
- `garden`: **Pebble Hop**, 25.31 s, 82 BPM. Fingerpicked strings, low/middle woody mallets and soft keys, with gaps between phrases.
- `medieval`: **Jester’s Pockets**, 22.77 s, 6/8 at dotted-quarter 92. Comic plucked dance with a piano response; no recorder or accordion.

All four share a new original middle-register motif beginning G4–E4–D4–E4 / A4–G4–E4. Every note, physical string excitation, resonator, keyboard, bass and percussion is generated by `Assets/Scripts/Stage3/Editor/Stage3MusicCompositionV2.py`. No third-party recordings, sample banks, Apple DLS, downloaded MIDI or external service was used. Reference direction: [Donut County’s publisher description](https://www.iam8bit.com/products/donut-county-2xlp-reissue) and [House House’s audio interview](https://fmod.com/blog/untitled-goose-game-interview); melodies are original.

WAVs are stereo 44,100 Hz / 16-bit PCM, peaks 0.516–0.560, RMS −19.34 to −20.50 dBFS, exactly silent endpoint frames. These numerical checks do not constitute artistic approval. The current manifest records revision, source, scored instruments and file hashes. Existing Unity Resource names and GUIDs are retained for audition controls.

The first set and exact original source are archived locally in `Builds/Stage3Review/MusicV1`; `Stage3MusicV1Manifest.json` preserves its metadata. The V1 renderer remains in source but now writes only to that archive. V2 score events and draft outputs are in `Builds/Stage3Review/MusicV2`; run `Stage3MusicCompositionV2.py` to reproduce them, then copy the reviewed `Demo*V2.wav` files to the corresponding `Resources/Stage3Music/Demo*.wav` paths. Read-only PCM verification: run the V2 source with `--check`, using Python with numpy.

## Audition

Use **Tools → Vodovorot → Stage 3 → Listen to music demos**, or embed
`Vodovorot.Stage3.Editor.Stage3MusicAudition.DrawControls()` in the review window.
Edit mode uses Unity's single-clip editor preview. Play mode uses the existing
Music settings bus, where zero is a true mute and the preference applies once.

The two victory-accent buttons require an active isolated rank simulation in
Play mode; first choose **Показать рейтинг сейчас** in the Stage 3 review window.
**Отдельно** stops the demo before the real SFX cue. **С музыкой** restarts the
selected theme (menu by default), waits 0.9 s for the music entrance and then
plays the same SFX cue with background ducking. Both respect the real 2.5 s
accent cooldown, so a just-completed automatic rank celebration does not swallow
the explicit audition. Stopping, leaving Play, reloading, ending/restarting the
simulation or stopping the pending background cancels a queued accent. No
profile, rank service or award is changed by these audio buttons.

QA entry point: `Stage3MusicAudition.PlayRankAccent(bool withBackground)` returns
whether the isolated audition was accepted. `RankAccentPending` reports a queued
cue; `CancelPendingRankAccent()` cancels it without changing the playing music.

The explicit runtime API is
`Vodovorot.Stage3.BackgroundMusicPlayer.PlayPreviewTheme("menu")` with `city`,
`garden`, `medieval` also accepted. `StopPreview()` stops both crossfade voices.
This API only starts auditions in Editor / Development builds. Scene changes
stop the preview. Ranking/results may freeze game time while music continues;
real YG pause, ads, application pause, listener pause and focus loss suspend it.

Rank improvement uses the existing **SFX** setting and SFX mixer route. A played
accent calls `DuckForRankAccent()` on an existing background player, without
starting music. At most two music sources exist; their equal-power crossfade,
0.28 nominal gain and 0.57 clip peak leave a conservative combined bound below
0.98 together with the existing Stage 2 absorption/accent maximum.

Current revision source: `Assets/Scripts/Stage3/Editor/Stage3MusicCompositionV2.py`; append `--check` for read-only verification.
