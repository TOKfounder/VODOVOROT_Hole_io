Пакет улучшений (авторизация уже дана; checkpoint на GitHub подтверждён)

P0. Награда за раунд и рекламные callback-и.
Наблюдение: полный City дал 0.2% и +0 XP/+0 монет (baseline-natural-results.jpg, baseline-card-02percent.jpg).
Решение: минимальная награда 5 XP/1 монета только за естественный полный раунд с полезным поглощением. Досрочный выход и пустой раунд минимума не дают. Все текущие старшие tiers сохраняются. x3 монет доступен один раз за результат; повтор, отмена, чужой ID и повторное открытие не начисляют снова.
Приёмка: интеграционные проверки пустого/полезного/досрочного/повторного сценария, настоящий полный WebGL-раунд, сохранение и повторный вход.

P1. Читаемый рост и обратная связь.
Наблюдение: HUD округляет 0.2% до 0%, роста до следующего уровня числом нет; +1 навсегда застыли поверх результатов.
Решение: десятые процента, размер/очки до следующего размера, корректная последняя ступень; обновление реальной fit-size после сглаживания роста; затухание очков при паузе; 00:00 после истечения таймера.
Приёмка: все пороги роста, физическая доступность объектов после роста, HUD в RU/EN и 1280x720, 390x844, 844x390; кадры до/после.

P1. Управление и обучение.
Решение: WASD/стрелки в дополнение к существующему mouse/touch drag, одинаковая диагональная скорость; сброс boost/joystick при потере фокуса/выключении. Обучение объясняет реальные способы ввода на устройстве и первую цель.
Приёмка: настоящий ввод WebGL, boost, pause/focus/return; мышь и мобильная раскладка сохранены.

P1. Камера.
Наблюдение: камера попала внутрь крупного объекта, закрыв почти весь мир (baseline-camera-occlusion.jpg).
Решение: локальное скрытие только заранее привязанных крупных заслоняющих Renderer, с восстановлением при выходе/disable. Материалы, коллайдеры, размеры и стоимость объектов сохраняются. Повторный проход уточнил граничный случай: камера ограничивает обзор областью карты с запасом, сохраняя игрока в безопасной части кадра; при угловом конфликте видимость игрока приоритетна.
Приёмка: перекрытие/восстановление на настоящем маршруте, границы карты, проверки всех трёх сцен.

P1. Ближайшая цель существующего метапрогресса.
Решение: понятное количество XP до следующего уровня в меню/прогрессе и результатах, единый источник 100 XP/уровень. Каталог META-020/META-021/META-026/META-041 использован как варианты; выбирается улучшение текущей шкалы, без новой валюты/коллекций/календаря. Сохранённый XP и текущие открытия сохраняются. Удалить неподтверждённый placeholder места 400. Сохранять уже просмотренные rewarded-этапы hand/bag/box при переходах/входе, однократно обрабатывать результат текущего запроса.
Приёмка: старое сохранение, новый профиль, XP/полоса/цель после раунда; повторный вход и отменённые/повторные rewarded-callback.

P1. Реклама и техническое качество.
Решение: межстраничная реклама только при возвращении из раунда, интервал >=180 с; убрать вызов при загрузке игровой сцены/первом запуске. Избежать повторных сохранений из рекурсивных slider events звука.
Приёмка: локальная SDK-симуляция, отсутствие рекламы посреди управления, сравнение сохранения и исходных настроек.

Стенд: сохранённая тестовая сцена настоящих систем с настройками duration/min XP/min coins/cutaway restore delay, restart/reset/save, отдельный профиль. В релизный список сцен не включается.

Карта влияния:
- Общий Assets/Prefabs/GamingPrefabs/ImmersivePack.prefab -> Low Poly City/Garden/MedievalCastle: игровые контроллеры, camera, HUD/результаты/обучение. Только относящиеся сериализованные поля и добавленные UI; GUID сохраняются.
- MainMenu.unity -> MainMenuController/ProgressController/HorizontalLayout3D: XP/уровень и отображение, существующие цены/открытия без замены.
- GamingManager -> EndGameController -> SaveProgress -> LeaderboardRoundService: базовая награда ровно один раз; рейтинг получает только уже сохранённый XP; подтверждённые места и бонус рейтинга не подменяются.
- MainMenuController -> rewarded SDK -> новые необязательные поля SavesYG: старые JSON получают нулевой прогресс; никаких переименований/изменений типов старых полей; IAP/production SDK не имитируются как проверенные.
- MovementScript -> JoystickController/BoostButton/Player Rigidbody: реальный ввод, clamp границ, сохранение скоростей.
- CameraCutawayView: только runtime Renderer.forceRenderingOff с восстановлением; не меняет материалы/физику и не скрывает мелкие съедобные цели.

Обязательные конечные проверки: компиляция; meaningful checks; сохранённые сцены/prefab; актуальная WebGL-сборка; фактический цикл и размеры; 19 активных CFP ID; итоговый аудит 2 Luna High + визуальный Terra High; исправления и повтор; финальный diff/commit/push и проверка remote. До этого Goal не завершать.
